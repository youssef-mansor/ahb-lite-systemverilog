# AMBA AHB-Lite SystemVerilog Project

This repository contains an **educational SystemVerilog implementation and verification of an AMBA AHB-Lite bus**.  
The goal of this project is to gain hands-on experience with **bus protocols, RTL design, and verification methodologies** by building a complete AHB-Lite system from scratch.

The project includes:
- An **AHB-Lite Master Bus Functional Model (BFM)**
- Multiple **AHB-Lite Slave** implementations
- A **self-checking testbench** with protocol assertions (SVA)
- Directed and constrained test scenarios to validate correct bus behavior

This repository is intended for **learning and experimentation**, with a strong emphasis on **protocol correctness, clean RTL design, and verification best practices**.
